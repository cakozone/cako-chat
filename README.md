# Cako Chat

**Todos os seus chats juntos.** Uma ferramenta Cako Tools gratuita e de código aberto para Windows x64.

Reúna Twitch, YouTube, Kick e TikTok em uma sobreposição para jogos ou no OBS, com fontes personalizáveis, emotes, badges disponíveis, perfis de canais, histórico da sessão e aviso sonoro opcional.

## Downloads

As versões são disponibilizadas em [Releases](https://github.com/cakozone/cako-chat/releases), com instalador, ZIP Windows, código-fonte correspondente e hashes SHA-256. A primeira versão está em preparação.

O código completo está no arquivo **Cako-Chat-1.0.0-Source.zip** anexado à versão. Os arquivos automáticos “Source code” do GitHub contêm apenas o conteúdo deste repositório de distribuição; utilize o ZIP de fonte nomeado acima para compilar o aplicativo.

## Instalação

Use o instalador ou extraia todo o ZIP Windows e abra **Cako Multichat.exe**. O nome interno anterior foi preservado por compatibilidade. Feche a versão anterior antes de atualizar; as preferências ficam no perfil do Windows.

A versão 1.0.0 não possui assinatura digital própria e pode apresentar aviso do Windows. Não desative antivírus ou firewall.

## Uso

Conecte os canais na aba Conexões. Em Ajustes, personalize o chat. Ativar chat mostra somente mensagens sobre o jogo; Ctrl+Shift+M recupera os controles. Para OBS, use a URL específica para fonte ou dock e mantenha o Cako Tools aberto no mesmo computador. Não compartilhe sua URL pessoal do OBS.

Capturas dependem dos serviços das plataformas; disponibilidade, emotes, badges e cores podem variar. TikTok automático utiliza assinatura externa Euler. Não é necessário cadastrar um aplicativo Twitch.
